# Returned report: Coding and communication

This is an authored evaluation fixture, supplied as a second returned knowledge
report rather than a retrieved primary source. Its citation metadata identifies
real publications; no independent primary-source reading is claimed.

Source coding concerns representing messages efficiently. Channel coding
concerns communicating through noise with controlled error. These objectives
connect through probability models but require different operations. For a
discrete memoryless channel, capacity is the maximum mutual information over
input distributions. Its operational interpretation concerns coding performance
under the channel model and asymptotic conditions, not a promise about any
particular finite-length implementation.

Entropy H(X), already central to the first topic, describes average uncertainty
in the source distribution. Learning coding theory also requires distinguishing
individual-message length, expected code length, and limiting rate. Toy examples
should state their probabilities and code assumptions.

Potential advanced topics include finite-blocklength bounds, universal coding,
and specific constructions. A short introductory guide can leave these in the
source notes while connecting uncertainty, compression, and noisy communication.
