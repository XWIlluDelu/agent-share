    Attention Is All You Need

    A reading note on Vaswani et al. (2017)

    01　Overview

    An attention-based architecture

    The Transformer uses attention and position-wise feed-forward layers in an encoder–decoder architecture. It removes recurrent and convolutional layers from the sequence model, enabling parallel computation across token positions during training.

    Key finding. Self-attention directly connects positions within a sequence, replacing the sequential computation required by recurrent layers.

    Encoder and decoder

    The encoder transforms the input sequence into contextual representations. The decoder combines masked self-attention with attention over the encoder output to predict the next token.

    Parallel computation during training and autoregressive generation are distinct: decoder masking prevents a position from attending to future output tokens.

    02　Method

    Scaled dot-product attention

    Queries and keys determine attention weights. A softmax normalizes these weights across keys, and the output is their weighted sum of the value vectors.

    $$ \operatorname{Attention}(\mathbf Q,\mathbf K,\mathbf V) =\operatorname{softmax}\!\left( \frac{\mathbf Q\mathbf K^\top}{\sqrt{d_k}}\right)\mathbf V. $$
    import torch

def attention(q, k, v):
    scores = q @ k.transpose(-2, -1) / q.size(-1) ** 0.5
    weights = torch.softmax(scores, dim=-1)
    return weights @ v

    Why scale the dot products?

    If query and key components are independent with zero mean and unit variance, the dot product has variance $d_k$. Dividing by $\sqrt{d_k}$ counteracts the growth of its magnitude, which would otherwise push softmax toward regions with small gradients.

    We suspect that for large values of $d_k$, the dot products grow large in magnitude, pushing the softmax function into regions where it has extremely small gradients.

    Multi-head attention

    Each head uses learned projections of the queries, keys and values. The heads operate in parallel; their outputs are concatenated and projected back into the model representation.

    $$ \begin{aligned} \mathrm{head}_j&=\operatorname{Attention} (\mathbf Q\mathbf W_j^Q,\mathbf K\mathbf W_j^K,\mathbf V\mathbf W_j^V),\\ \operatorname{MultiHead}(\mathbf Q,\mathbf K,\mathbf V) &=\operatorname{Concat}(\mathrm{head}_1,\ldots,\mathrm{head}_h)\mathbf W^O. \end{aligned} $$

    Encoding sequence position

    Position information is added to the token embeddings. The paper uses sinusoidal functions with different frequencies:

    $$ \begin{aligned} \mathrm{PE}_{p,2i}&=\sin\!\left(p/10000^{2i/d_{\mathrm{model}}}\right),\\ \mathrm{PE}_{p,2i+1}&=\cos\!\left(p/10000^{2i/d_{\mathrm{model}}}\right). \end{aligned} $$
    Mathematical detail: Why sinusoidal frequencies?

    For any fixed offset $k$, $\mathrm{PE}_{pos+k}$ can be represented as a linear function of $\mathrm{PE}_{pos}$. By using trigonometric addition formulas, $\sin(\omega(pos+k)) = \sin(\omega pos)\cos(\omega k) + \cos(\omega pos)\sin(\omega k)$. The corresponding cosine identity completes a linear transformation of each sine–cosine pair.

    04　Computational trade-offs

    Sequence length and computation

    Table 1 compares the dependence on sequence length $n$ and representation dimension $d$. A self-attention layer requires $\mathcal O(n^2d)$ computation, whereas a recurrent layer requires $\mathcal O(nd^2)$.

    Vaswani et al. (2017), Table 1: maximum path lengths, per-layer complexity and minimum number of sequential operations for different layer types.

    Limitation. Full self-attention compares every query position with every key position. Its attention computation grows quadratically with sequence length.

    The paper's own mitigation for very long sequences is to restrict self-attention to a neighborhood of size $r$ around each output position, which raises the maximum path length to $\mathcal O(n/r)$.

    Dependency paths

    The same comparison gives self-attention a constant maximum path length between positions within a layer, versus a path length that grows with sequence length for recurrent computation. This is a structural advantage for connecting distant positions.
